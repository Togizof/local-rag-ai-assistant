PROJECT DESCRIPTION: LOCAL RAG AI ASSISTANT
------------------------------------------

1. Overview
This project is an offline Retrieval-Augmented Generation (RAG) assistant utilizing the Microsoft Foundry Local framework.
The system reads, processes, and indexes user-provided documents (such as lecture notes, user manuals, or FAQ pages) locally, and uses a local Large Language Model (LLM) to answer questions based on the ingested context.

2. Architectural Components
- User Interface Layer (Streamlit & CLI): Interactive web and console dashboards allowing users to ask questions and upload new documents.
- Pipeline Orchestration Layer: Manages text chunking, triggers embedding generation, and sends augmented prompts to the LLM.
- Data Layer (SQLite): Stores document text chunks and their corresponding 1024-dimensional embedding vectors.
- AI Layer (Foundry Local): Hardware-accelerated (CPU/NPU) local inference engine that manages the qwen3-embedding-0.6b and phi-3.5-mini models.

3. Technological Features and Benefits
- Zero Internet Dependency: Requires no external API keys or network connection. Your data remains entirely private on your local machine.
- Smart Text Chunking: Uses a "Sentence-Aware Chunker" that respects sentence boundaries to prevent context splitting.
- Cosine Similarity: Uses Cosine Similarity metrics with NumPy (and a pure-Python fallback mechanism) to perform similarity search.
