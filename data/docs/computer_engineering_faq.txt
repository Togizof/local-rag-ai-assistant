COMPUTER ENGINEERING DEPARTMENT - GRADUATION PROJECT FAQ
---------------------------------------------------------

Question 1: How should I choose my graduation project topic?
Answer: Project topics should target current problems in computer engineering. Fields such as artificial intelligence, data science, embedded systems, web, and mobile technologies are preferred.

Question 2: In which language should the project reports be written?
Answer: Unless specified otherwise, reports must be written in formal, clear English or Turkish according to academic writing guidelines. Technical terms can be specified in parentheses.

Question 3: Can offline/local LLM models be used in the graduation project?
Answer: Yes. For projects requiring data privacy and offline capability, local inference engines like Microsoft Foundry Local running Phi-3.5 or Qwen models are highly recommended.

Question 4: What are the project evaluation criteria?
Answer: Projects are evaluated based on code quality, documentation completeness, presentation success, innovation, and whether the project is in a working, ready-to-publish state.
